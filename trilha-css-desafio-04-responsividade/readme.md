# Discord — página responsiva

Projeto educacional que reproduz a estrutura da página inicial do Discord com foco em responsividade e nos conceitos de CSS Flexbox.

## Tecnologias

- HTML5 semântico
- CSS3
- Flexbox
- Media queries
- Google Fonts: Open Sans e Luckiest Guy

## Estrutura

- `index.html`: cabeçalho, chamadas para ação, quatro seções de conteúdo e rodapé.
- `styles.css`: estilos, ilustrações construídas com CSS e ajustes para telas menores.

## Como executar

1. Baixe ou clone os arquivos do projeto.
2. Mantenha `index.html` e `styles.css` na mesma pasta.
3. Abra `index.html` em um navegador.

As ilustrações foram criadas com elementos HTML/CSS como substitutas visuais, pois os arquivos de imagem originais do layout de referência não foram fornecidos. As fontes são carregadas do Google Fonts quando há conexão com a internet.

> Este é um projeto de estudo, sem vínculo oficial com o Discord.
