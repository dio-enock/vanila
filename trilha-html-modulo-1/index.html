História dos computadores

A história dos computadores começou muito antes dos computadores modernos. Um dos instrumentos mais antigos utilizados para realizar cálculos foi o ábaco.

Com o passar do tempo, surgiram máquinas cada vez mais sofisticadas. Durante o século XX, os computadores passaram por uma grande evolução, tornando-se menores, mais rápidos e acessíveis.

Atualmente, os computadores estão presentes em praticamente todas as áreas da sociedade. Computação e tecnologia fazem parte do nosso cotidiano.

Uma característica importante dessa evolução foi a redução do tamanho dos componentes. Equipamentos que antes ocupavam salas inteiras hoje podem caber na palma da mão.

"O computador é uma ferramenta que amplia a capacidade humana de processar informações."

Para conhecer mais sobre a história da computação, consulte este material.

O que são Clients?

Em uma rede de computadores, um client é um dispositivo ou programa que solicita algum serviço ou recurso a outro computador.

Um exemplo bastante comum é o navegador de internet. Quando acessamos um site, o navegador funciona como um cliente ao fazer uma solicitação para um servidor.

Podemos representar uma comunicação simples assim:

  1. O usuário acessa um endereço no navegador.
  2. O navegador envia uma solicitação.
  3. O servidor recebe a solicitação.
  4. O servidor processa a requisição.
  5. O servidor devolve uma resposta ao cliente.

O termo HTTP é utilizado para representar um dos principais protocolos envolvidos na comunicação entre clientes e servidores na Web.

Exemplo: um navegador como Chrome ou Firefox pode atuar como cliente.

O que são Servers?

Um server, ou servidor, é um computador ou sistema responsável por disponibilizar recursos e serviços para outros dispositivos conectados a uma rede.

Quando acessamos um site, normalmente o navegador envia uma solicitação para um servidor. Esse servidor pode processar a solicitação e retornar informações para o navegador.

Existem diferentes tipos de servidores. Alguns exemplos são:

  • Servidor Web;
  • Servidor de banco de dados;
  • Servidor de arquivos;
  • Servidor de e-mail.

Uma aplicação pode utilizar, por exemplo, um servidor para armazenar informações e outro para disponibilizar uma página Web.

Cliente e servidor trabalham juntos para permitir a troca de informações em uma rede.

Como é uma estrutura básica de um HTML?

Um documento HTML possui uma estrutura formada por elementos e tags. A declaração <!DOCTYPE html> informa ao navegador que o documento utiliza HTML5.

A tag <html> representa o elemento raiz do documento. Dentro dela normalmente encontramos as tags <head> e <body>.

A seção <head> contém informações sobre o documento, enquanto o <body> contém o conteúdo que será apresentado ao usuário.

Exemplo de hierarquia

  1. DOCTYPE
  2. HTML
  3. HEAD
  4. BODY

Também podemos utilizar títulos de diferentes níveis:

Título de nível 4

Título de nível 5
Título de nível 6

Podemos escrever informações como H2O utilizando <sub> e expressões matemáticas como 23 utilizando <sup>.

Algumas informações antigas podem ser apresentadas com texto removido.

Entendendo a diferença entre listas ordenadas e não ordenadas

As listas são utilizadas para organizar informações. Existem dois tipos muito comuns em HTML: listas ordenadas e listas não ordenadas.

Lista não ordenada

A lista não ordenada é criada utilizando a tag <ul>. Seus itens são representados pela tag <li>.

  • HTML
  • CSS
  • JavaScript

Lista ordenada

A lista ordenada utiliza a tag <ol>. Os itens aparecem seguindo uma ordem numérica.

  1. Aprender HTML
  2. Aprender CSS
  3. Aprender JavaScript

Portanto, a principal diferença é que a lista ordenada representa uma sequência, enquanto a lista não ordenada apresenta os itens sem uma ordem numérica específica.
