# Desafio Flexbox

Clonar a pagina do youtube 2024~

O layout utiliza display: flex, align-items, justify-content, gap, flex-wrap e flex-shrink para organizar os elementos.

As miniaturas, o avatar e a logo do player foram construídos com CSS e elementos HTML para que a página funcione sem depender de arquivos de imagem adicionais. 
Portanto, são aproximações visuais, não reproduções exatas das imagens originais do YouTube.

Os botões e o campo de pesquisa estão presentes visualmente, mas não possuem funcionalidades de backend.
